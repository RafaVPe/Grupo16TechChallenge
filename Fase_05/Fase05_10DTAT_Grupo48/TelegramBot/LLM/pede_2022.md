## 1. Contexto e Metodologia

O **PEDE (Programa de Educação para o Desenvolvimento)** da Associação Passos Mágicos
avalia anualmente os alunos por meio do **INDE — Índice de Desenvolvimento Educacional**,
composto por 7 indicadores em duas faixas de fase:

- **Fases 0–7:** `INDE = IAN×0,10 + IDA×0,20 + IEG×0,20 + IAA×0,10 + IPS×0,10 + IPP×0,10 + IPV×0,20`
- **Fase 8 (Universitários):** `INDE = IAN×0,10 + IDA×0,40 + IEG×0,20 + IAA×0,10 + IPS×0,20  (IPP e IPV N/A)`

**Pedras-conceito (faixas INDE):**

| Pedra | Intervalo INDE |
|-------|---------------|
| Quartzo | 3,0 – 6,1 |
| Ágata | 6,1 – 7,2 |
| Ametista | 7,2 – 8,2 |
| Topázio | 8,2 – 9,4 |

**Faixas IAN (defasagem de nível):**

| Categoria | Critério D = fase efetiva − fase ideal |
|-----------|---------------------------------------|
| Em fase (IAN 10) | D ≥ 0 |
| Defasagem Moderada (IAN 5) | 0 > D ≥ -2 |
| Defasagem Severa (IAN 2,5) | D < -2 |
